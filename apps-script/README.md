# ติดตั้งระบบรับแจ้งน้ำท่วมจากประชาชน (Google Sheets + Apps Script)

ใช้เวลาประมาณ 10 นาที ทำครั้งเดียว ไม่มีค่าใช้จ่าย

## 1. สร้าง Google Sheet
1. เปิด https://sheets.new (ใช้บัญชี Google ที่จะเป็น **แอดมิน**)
2. ตั้งชื่อไฟล์ เช่น `bkk-flood-map รายงานจากประชาชน`

## 2. ใส่สคริปต์
1. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ในโฟลเดอร์นี้
3. กด 💾 บันทึก
4. เลือกฟังก์ชัน **`setup`** ในแถบด้านบน แล้วกด **▶ Run**
5. Google จะขอสิทธิ์ → **Review permissions** → เลือกบัญชี → **Advanced → Go to (unsafe)** → **Allow**
   (สคริปต์ขอสิทธิ์แก้ไขชีตนี้และสร้างโฟลเดอร์เก็บรูปใน Google Drive ของคุณ)
6. กลับไปที่ชีต จะเห็นแท็บ `Reports` และ `Log` ถูกสร้างขึ้น

## 3. Deploy เป็น Web App
1. ใน Apps Script กด **Deploy → New deployment**
2. กดรูปเฟือง ⚙ เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** `Me` (ตัวคุณ)
   - **Who has access:** `Anyone`
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/` ลงท้ายด้วย `/exec`)

## 4. เปิดใช้บนเว็บ
ส่ง URL ให้ผู้พัฒนา หรือแก้ไฟล์ `data/report-config.json` ใน repo เอง:
```json
{ "endpoint": "https://script.google.com/macros/s/xxxxxxxx/exec" }
```
เมื่อ push แล้ว ปุ่ม **📍 แจ้งน้ำท่วม** บนเว็บจะใช้งานได้

> URL นี้เป็นที่อยู่สาธารณะที่เว็บเรียกใช้อยู่แล้ว ไม่ใช่รหัสลับ แต่อย่าแชร์ลิงก์ของ Google Sheet ให้คนอื่น เพราะในชีตมีชื่อเต็มของผู้แจ้ง

## การใช้งานของแอดมิน
- **ชีต `Reports`** = สถานะปัจจุบันของทุกหมุด (open / closed / hidden)
- **ชีต `Log`** = ทุกการกระทำ ต่อท้ายอย่างเดียว: เวลา, การกระทำ, รหัสหมุด, **ชื่อเต็มผู้ทำ**, รหัสอุปกรณ์, browser, ตำแหน่ง, ระดับน้ำ, ข้อความ, รูป/วิดีโอ และ hash
- **รูป/วิดีโอ** อยู่ในโฟลเดอร์ `bkk-flood-map uploads` ใน Google Drive (ค้นหาด้วยรหัสไฟล์ในช่อง `photo_ids`)
- เมนู **น้ำท่วม (แอดมิน)** ที่แถบเมนูของชีต:
  - **ซ่อนรายงานในแถวที่เลือก** – สำหรับรายงานเท็จ/ไม่เหมาะสม (บันทึกใน Log ว่าแอดมินคนไหนซ่อน พร้อมเหตุผล)
  - **กู้คืนรายงาน** – เปิดหมุดอีกครั้ง เช่น มีคนกด "น้ำลดแล้ว" มั่ว
  - **ตรวจสอบความถูกต้องของ Log** – ตรวจ hash ทุกแถว ถ้ามีการแก้ไขบันทึกย้อนหลังจะบอกแถวที่ถูกแก้
- **ห้ามแก้ไขหรือลบแถวในชีต Log ด้วยมือ** (ชีตถูกตั้งให้เตือนก่อนแก้) ถ้าแก้ การตรวจสอบจะไม่ผ่าน

## ถ้าแก้โค้ดใน Code.gs ภายหลัง
Deploy → **Manage deployments** → ✏️ แก้ deployment เดิม → Version: **New version** → Deploy
(URL เดิมใช้ต่อได้ ไม่ต้องเปลี่ยน `report-config.json`)

## ข้อจำกัด
- ระบุตัวตนด้วยการกรอกชื่อเท่านั้น (ไม่มีการล็อกอิน) จึงบันทึกรหัสอุปกรณ์และ browser ไว้ช่วยตรวจสอบย้อนหลัง
  Apps Script ไม่เห็น IP ของผู้ใช้
- จำกัดการแจ้งไม่เกิน 6 ครั้ง / 10 นาที / อุปกรณ์ และรับเฉพาะพิกัดในกรุงเทพฯ
- Google จำกัดการทำงานพร้อมกันประมาณ 30 คำขอ ช่วงคนแจ้งพร้อมกันมากอาจช้าหรือต้องลองใหม่
- รูปย่อจากมือถือก่อนส่ง (~200–400 KB/รูป) วิดีโอไม่เกิน 20 วินาที / 15 MB พื้นที่ Google Drive ฟรี 15 GB
